# HR-Analytics-Dashboard-Power-BI-
Interactive HR Analytics Dashboard built using Power BI to analyze workforce trends, employee distribution, attrition, and key performance metrics through data visualization.

## Overview
This project is a **data visualization dashboard built using Power BI** to analyze HR data and extract meaningful insights about workforce trends, employee behavior, and organizational metrics.
The dashboard helps in understanding patterns such as employee distribution, attrition, and key HR indicators in a visually intuitive manner.

## Objectives
- Analyze employee data efficiently
- Visualize workforce trends and patterns
- Identify key HR insights for decision-making
- Present data in an interactive and user-friendly format

## Project Files
- `hr-analytics-dashboard.pbix` → Power BI dashboard file  
- `hr_dataset.xlsx` → Raw dataset used for visualization  

## Tools & Technologies
- **Power BI**
- **Microsoft Excel**
- Data Cleaning & Transformation
- Data Visualization Techniques
